# 美股投资研究看板：设计规格

日期：2026-09-10  
状态：待用户审阅  
范围：个人使用、只读、以美股长期基本面研究为核心的多标的看板。

## 1. 目标与原则

系统为用户提供可复核的投资研究工作流，而非交易或荐股系统。用户可维护多只美股的观察列表，定时获取市场与财报数据，查看基本面、估值、财报预期变化、同行对比和辅助技术指标，并长期记录和复盘自己的判断。

所有输出必须明确属于下列三类之一：

- **事实**：来源文件或 API 返回的原始数据，附来源、抓取时间和适用期间。
- **计算结果**：由事实数据按已知公式得到的指标，附公式版本。
- **用户判断**：用户填写的投资逻辑、假设、仓位和失效条件，不伪装成事实或系统预测。

系统不调用下单、资金或持仓变更接口；不输出必买、必卖或自动仓位建议。

## 2. 技术选型

第一版采用本地优先架构：Python 负责采集、计算与调度，SQLite 负责持久化，Streamlit 提供本机浏览器看板。

## 3. 数据源与边界

### Moomoo

Moomoo MCP 用于交互式研究查询。无人值守的本地定时任务使用 Moomoo OpenD/API，避免任务依赖某个对话或 MCP 会话在线。二者通过同一个只读 `MarketDataProvider` 适配器暴露，应用层不依赖具体接口。

适配器优先提供：报价、历史日线/K 线、公司基本信息、市值、财报日历、EPS/营收/EBIT 实际值与市场预期、分析师共识和历史财报前后价格表现。实现前需依据已安装 MCP 的实际工具定义完成字段映射。若特定 MCP 字段不可用于定时任务，以 OpenD/API 的等价只读接口补充。

### SEC EDGAR 与公司 IR

SEC EDGAR/XBRL 与公司的 Investor Relations 文件是美股财务事实的主证据源。系统读取 10-K、10-Q、8-K 等文件及 XBRL 公司事实，提取营收、毛利、营业利润、净利润、经营现金流、资本开支、自由现金流、现金、债务、股本等标准指标。

每项展示数据提供 EDGAR 或 IR 原文链接。对公司自定义的非 GAAP 指标和行业关键指标，第一版允许记录原文、单位、期间和来源，但不假设可跨公司直接比较。

### 用户输入

用户维护观察列表、同行组及判断日志。同行组由用户显式设置，避免通用行业标签产生不合理的可比公司集合。

## 4. 数据模型

- `security`：代码、名称、交易所、CIK、币种、状态。
- `watchlist` 与 `watchlist_member`：观察列表和多标的成员。
- `peer_group` 与 `peer_group_member`：用户定义的同业比较集合。
- `financial_fact`：标准化财务事实；保存数值、单位、期间起止、报送期、来源链接、抓取时间与原始标签。
- `filing`：申报元数据、文件哈希、来源 URL 与解析状态；不保存重复的整份申报正文。
- `price_bar`：日线 OHLCV 与复权信息。
- `estimate_snapshot`：EPS、营收、EBIT 等预期值；只在值发生变化时新增快照。
- `derived_metric`：增长率、TTM、估值、技术指标等，带输入版本、计算时间和公式版本。
- `earnings_event`：财报日期、实际值、预期、差异、指引结论待复核状态及财报后价格窗口表现。
- `research_judgment`：用户的买入逻辑、增长来源、估值假设、目标仓位、失效条件、结论与复盘。
- `dashboard_alert`：仅在看板内显示的待办和重要变化。
- `job_run` 与 `cleanup_audit`：任务状态、错误、重试、处理数据量和清理记录。

每个外部事实都有来源、抓取时间和适用期间。事实不会被派生指标或用户判断覆盖。

## 5. 指标与研究视图

### Watchlist 总览

每只股票显示当前价格与市值、主要估值倍数、营收/利润/FCF 增速、现金债务健康度、下一财报日、预期最近变化、同行区间和技术面状态。数据不可用或过期时显式标注。

### 单股研究页

页面分为“事实”“计算结果”“我的判断”三栏。包含业务摘要、最新申报文件、季度与 TTM 趋势、资产负债表、现金流、估值历史、同行比较、关键风险和判断日志。

### 财报复盘页

在财报前保存当时可获得的共识预期；发布后对比实际 EPS、营收、EBIT 与预期，记录公司指引的上调、持平、下调或待人工确认状态，并计算财报后第 1、5、20 个交易日的股价表现。

### 技术面

技术指标仅用于描述趋势、成交活跃度和动量，不能视为预测或交易信号。第一版包含：

- 20、50、200 日简单移动平均线。
- 当日成交量与 20 日平均成交量的比值。
- RSI(14)，采用 Wilder 平滑方法。
- MACD(12, 26, 9)。
- 52 周高低点以及按近期价格拐点计算的支撑/阻力价格区间。

所有指标显示输入周期、计算日期和公式版本。

## 6. 定时任务与看板提醒

提醒只生成在看板内，不发送邮件或桌面通知。

- 每个美股交易日盘后：采集价格、更新技术指标、更新估值与观察列表状态。
- 财报前 3 天：创建待办，展示当季共识预期、上次公司指引与需要复核的既有判断。
- 财报发布后：采集实际值与最新预期，计算差异，创建“阅读指引与管理层解释”的待办；系统不自动把文本解释为投资结论。
- 每周末：创建仅包含实质变化标的的周报待办。
- 每周：执行数据保留清理并记录审计结果。

任务必须幂等：同一日期同一标的的成功任务可安全重跑，不能产生重复行情、预期快照或提醒。失败时保留最近有效数据，记录失败原因和过期状态，再按受限重试策略重试。

## 7. 保留与清理策略

- 永久保留用户判断、复盘、同行组、来源链接和已引用的关键财务事实。
- 日线保留 5 年；盘中数据仅保留最近 30 天。
- 申报原文只做 7 天本地缓存，之后删除缓存；保留文件元数据、哈希、链接及提取事实，以便重新拉取。
- 预期快照仅在发生变化时保存，保留 2 年。
- 自动报告、任务运行和详细错误日志保留 90 天；聚合运行统计保留。
- 每周清理前计算目标数据量，清理后写入 `cleanup_audit`；看板提供当前存储用量、分类占比、保留规则、导出和手动清理入口。
- 每月执行 SQLite 空间整理。绝不自动删除用户的投资判断。

此策略面向 50–100 个标的，目标占用为几十至数百 MB，而非无上限增长。

## 8. 可靠性、安全与可审计性

- 数据源出现错误、字段缺失或相互冲突时，不静默填充；看板显示数据过期或待确认状态。
- 所有数据源连接均只读。账号信息、令牌和登录信息存于环境变量或操作系统安全存储，绝不写入数据库或版本控制。
- 计算指标保存原始输入版本和算法版本，保证历史报告可解释。
- 看板显示最近任务状态、最后成功时间和数据时效。
- 个人笔记可导出为可移植格式，数据库可备份与恢复。

## 9. 验证策略

- 单元测试：同比/环比、TTM、自由现金流、P/E/P/S/EV 倍数、RSI、MACD、移动均线及所有保留策略。
- 数据契约测试：Moomoo 适配器和 EDGAR 适配器的字段映射、单位、日期和空值处理。
- 集成测试：使用固定的申报和行情样本，验证“预期快照 → 财报实际值 → 差异计算 → 看板提醒”的流程。
- 端到端测试：新建观察列表、添加标的、运行一次盘后任务、打开看板、保存一条判断、执行清理任务。
- 人工验收：选取用户熟悉的公司，将展示数字与原始 10-K/10-Q、IR 财报稿和 Moomoo 数据逐项比对。

## 10. 非目标与后续候选项

第一版不包含自动交易、下单、自动调仓、收益承诺、社交情绪驱动交易信号、邮件/桌面推送或多用户协作。

后续可在不改变事实—计算—判断分层的前提下增加：港股/A 股、多套估值模型、预期修正趋势图、财报电话会文本的人工辅助摘要、只读券商持仓导入和外部通知渠道。
